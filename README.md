# Ball Battle 🎮

Hauska, selaimessa toimiva trampoliinitaistelupeli. Pelaa tekoälyvastustajaa vastaan, potki erilaisia palloja ja selviydy yllätyksellisistä kaaostapahtumista!

## Pelaaminen

- **A / D** – liiku
- **W** – hyppää
- **Välilyönti** – potkaise
- **1–9 ja 0** – vaihda palloa
- **G** – vaihda hanskoja

Pelissä on valittavia hahmoja, vaikeustasoja, maailmoja, trampoliineja ja varusteita.

## Käynnistys

Peli on itsenäinen HTML-sovellus ilman palvelinpuolen komponentteja. Avaa `index.html` selaimessa tai julkaise repositorio GitHub Pagesilla.

## GitHub Pages

1. Lisää pelin HTML-tiedosto repositorion juureen nimellä `index.html`.
2. Avaa **Settings → Pages**.
3. Valitse **Deploy from a branch**, haaraksi **main** ja kansioksi **/(root)**.
4. Julkaisun osoite on https://jalunden.github.io/ball-battle/.
