# Ball Battle – omat taustat

Lisää tähän kansioon PNG-, JPG- tai WebP-kuvia GitHubin **Add file → Upload files** -toiminnolla.

Peli hakee tämän kansion kuvat automaattisesti GitHubin julkisesta rajapinnasta. Kuvien tiedostonimistä muodostetaan nimet Maailma-valikkoon.

Suositeltu kuvakoko: **1920 × 1080** tai **1280 × 720** (16:9). Käytä selkeitä nimiä, esimerkiksi `Karkkimaa.png` tai `Avaruusasema.png`.

GitHub Pages -julkaisu voi kestää hetken latauksen jälkeen. Päivitä pelin taustakirjasto asetuksista. Älä poista tätä README-tiedostoa, jos kansio olisi muuten tyhjä.
